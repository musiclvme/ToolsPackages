# SIGLAB · 信号处理实验台

浏览器里对比滤波前后的**时域波形**与**频域幅度谱**，为 AMR 等语音编解码打基础。

## 运行

在本目录起一个静态服务即可（ES module 需要 HTTP，不能直接 `file://`）：

```bash
cd signal_lab
python3 -m http.server 8765
```

浏览器打开 `http://localhost:8765`。

## 能做什么

- **输入**：正弦、双音、方波、扫频、噪声、冲激、类语音、上传 WAV
- **算法**：FIR 高/低/带通/带阻、一阶 IIR、预加重/去加重（AMR 前端常用）、滑动平均、Hamming 窗
- **图**：时域叠加、频谱叠加、FIR 频率响应；可试听输入/输出

默认采样率 **8 kHz**（窄带 AMR）。
